# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in public issues, discussions, or
pull requests. Use GitHub's **Report a vulnerability** feature in this
repository's Security tab to submit a private report. Include the affected
component and version or commit, impact, safe reproduction steps, and any
suggested mitigation.

If private reporting is unavailable, contact the repository owner through
the contact method on the SiNAVM GitHub profile and request a private channel.
Do not publish exploit details.

## Coordinated disclosure

Allow reasonable time for investigation and remediation, and coordinate
public disclosure with the maintainer. Do not access, alter, or exfiltrate
data that is not yours, or disrupt services during testing.

This policy covers only assets SiNAVM owns or is authorized to maintain. It
does not authorize testing third-party services or upstream projects, grant
legal immunity, or override applicable law. Reports will be reviewed as
reasonably practicable; no fixed response or remediation deadline is promised.
